# Injectors

Ferramentas de injeção preservadas por arquitetura.

## x64

`x64/PID_Injector_x64.exe`

- formato: PE32+
- arquitetura: x86-64
- usado com os projetos/builds x64

O mesmo binário também aparece dentro do snapshot histórico:

`reference/x64/ABIBuilder_V1_3/PID_Injector.exe`

O arquivo foi reutilizado pelo mesmo Git blob, sem alterar os bytes.

## x86

O injector x86 usado atualmente no Ramonia permanece em:

`research/ramonia_x86/tools/injector/PID_Injector_x86.exe`

Enquanto o trabalho do Ramonia estiver em andamento, ele fica junto da pesquisa x86 para evitar confundir os dois executáveis.
